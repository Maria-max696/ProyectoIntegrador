# Escalones de Vida

Escalera hidropónica NFT de cuatro niveles con dos nodos ESP32, sensores y panel web.
Universidad de San Buenaventura, Bogotá · Tecnología en Automatización Industrial · Laboratorio de IoT.

## Estructura del repositorio

| Carpeta o archivo | Contenido |
| --- | --- |
| `index.html`, `proyecto.html`, `sensores.html`, `resultados.html`, `contacto.html` | Sitio web |
| `css/site.css`, `js/site.js` | Estilos y comportamiento compartidos |
| `assets/images/` | Imágenes y curvas de calibración |
| `assets/docs/Escalones_de_Vida_Informe.pdf` | Informe técnico |
| `sensores/` | Códigos de los nodos ESP32 y de cada sensor |

## Importante: no subas contraseñas

No escribas la clave del WiFi ni direcciones IP reales en los archivos que subes a GitHub. Usa marcadores como `CLAVE_DE_TU_RED` y escribe los valores reales solo en tu computador.
